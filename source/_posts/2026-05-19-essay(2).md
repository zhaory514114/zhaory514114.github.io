## 思路

非常板的对顶堆（动态中位数）。

维护一个大根堆和一个小根堆，并确保：

1. 大根堆存放较小的一半元素，堆顶一定是这半部分的最大值。
2. 小根堆存放较大的一半元素，堆顶一定是这半部分的最小值。
3. 维护平衡：大根堆比小根堆多一个元素，此时大根堆的堆顶就是中位数。

如果发现堆不平衡，要取出多的元素放到另一个堆里。

## code

```cpp
#include <bits/stdc++.h>
using namespace std;
int main () {
	int x;
	cin >> x;
	priority_queue<int> minn;
	priority_queue<int, vector<int>, greater<int> > maxn;
	int q;
	cin >> q;
	minn.emplace (x);
	while (q --) {
		int lst = minn.top ();
		int a, b;
		cin >> a >> b;
		if (a <= lst) minn.emplace (a);
		else maxn.emplace (a);
		if (b <= lst) minn.emplace (b);
		else maxn.emplace (b);
		if (minn.size() > maxn.size () + 1) {
			maxn.emplace (minn.top ());
			minn.pop ();
		}
		else if (maxn.size () > minn.size ()) {
			minn.emplace (maxn.top ());
			maxn.pop ();
		}
		cout << minn.top () << endl;
	} 
	return 0;
}
```
