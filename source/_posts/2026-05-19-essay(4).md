## 思路

考虑到满足条件的子串只有一个要求：以 `C` 为中心（偶数长度的字符串没有单个字符的中心）。所以我们只需要枚举字符串 $S$ 的每一位，如果第 $i$ 位是 `C` 那么一定存在满足要求的子串。

如何计数？我们以每个字符 `C` 为中心向外扩展。

以字符串 `SMBCPROGR` 为例：

我们找到第一个 `C` 时的索引是 $i=3$。此时以该位为中心的最长子串是 `SMBCPRO`。

不难发现每次加上的个数是是该位到字符串两端的距离的较小值。

## code

```cpp
#include <bits/stdc++.h>
using namespace std;
int main () {
	string s;
	long long cnt = 0; // 见祖宗警告
	cin >> s;
	for (int i = 0; i < s.size(); i ++) {
		if (s[i] == 'C') {
			int len = s.size ();
			cnt += min (i - 0 + 1, len - i); // 加上以该位为中心的符合标准的子串个数
			//cout << i << ' ' << min (i - 0 + 1, len - i) << endl;
		}
	} 
	cout << cnt;
	return 0;
}
```
