## 思路

根据题意，打印机的内存具有后进先出的性质，即最后放入的文件会最先被打印，因此可以使用栈模拟整个过程。

维护一个栈 $t$，记录已经扫描但尚未打印的文件编号，同时使用数组标记每个文件是否已经被打印。

按照顺序遍历字符串 $s$，根据当前命令进行不同操作：

- 当 $s_i=1$ 时，将当前文件编号 $i$ 入栈，表示文件被扫描并存入内存。
- 当 $s_i=2$ 时，如果栈非空，则打印栈顶文件，将对应的 $p$ 标记为 `true` 并弹出栈顶；否则直接打印当前文件 $i$。
- 当 $s_i=3$ 时，直接打印当前文件 $i$，将 $p_i$ 标记为 `true`。

所有命令执行完毕后，遍历 $p$ 数组，所有仍为 `false` 的位置就是未被打印的文件编号。

## 代码

```
#include <bits/stdc++.h>
#define rep(i,j,k) for (int i = (j); i <= (k); i ++)
#define per(i,j,k) for (int i = (j); i >= (k); i --)
#define uint unsigned int
#define ll long long
#define ull unsigned long long
#define db double
#define ldb long double
#define mkp make_pair
#define eb emplace_back
#define e_ emplace
#define ls (p << 1)
#define rs (p << 1 | 1)
//#define int ll
using namespace std;
//const int N = ;
//const int MOD = 998244353;
//const int MOD = 1000000007;
const int INF = 0x3f3f3f3f;
const ll LINF = 4e18;
int T;

signed main () {
    ios::sync_with_stdio (0);
    cin.tie (0);
    cin >> T;
    while (T --) {
        int n;
        string s;
        cin >> n >> s;
        bool p[n + 1];
        rep (i, 1, n) p[i] = false;
        s = " " + s;
        stack<int> t;
        rep (i, 1, n) {
            if (s[i] == '1') t.e_ (i);
            else if (s[i] == '2') {
                if (! t.empty ()) {
                    p[t.top ()] = true;
                    t.pop ();
                }
                else p[i] = true;
            }
            else p[i] = true;
        }
        int cnt = 0;
        rep (i, 1, n) if (! p[i]) cnt ++;
        cout << cnt << '\n';
        rep (i, 1, n) if (! p[i]) cout << i << ' ';
        cout << '\n';
    }
    return 0;
}
```

## 时间复杂度

每个文件最多入栈一次、出栈一次，栈的每次操作均为 $O(1)$，遍历命令和统计答案各需要 $O(n)$ 的时间。
